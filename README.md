# PFL Projects

This repository contains the two projects developed for the Functional and Logic Programming course at FEUP.

## Haskell Project: Solving Graph Problems

**Repository:** [Haskell](PFL_TP1_T14_G09)

This project focuses on solving various graph-related problems using Haskell. It explores concepts such as graph traversal, shortest path algorithms, and other computational techniques relevant to graph theory.

## Prolog Project: Collapse Game

**Repository:** [Prolog](PFL_TP2_T14_Collapse_9)

This project implements the Collapse Game using Prolog. The goal is to apply logical programming techniques to create an interactive and intelligent gameplay experience, leveraging Prolog's pattern-matching and rule-based inference capabilities.
